# Ritwik Gupta – Portfolio

Dark manga scroll portfolio. React + Vite.

- Edit your content in `src/data.js` (links, stats, missions, skills). Chapter text lives in `src/App.jsx`.
- Run locally: `npm install` then `npm run dev`
- Deploy: push to `main`, then in the repo go to Settings → Pages → Source: **GitHub Actions**. The included workflow builds and publishes it.
